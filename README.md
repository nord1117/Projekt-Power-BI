  Demografická analýza měst Středočeského kraje

**Projekt v rámci Datové Akademie Engeto**

* **Popis:** Interaktivní Power BI report analyzující vývoj obyvatelstva, migraci, porodnost, úmrtnost, sňatky a rozvody pro města Benešov, Beroun a Kolín.
* **Použité techniky:** Transformace dat v Power Query (sloučení tabulek měst), tvorba DAX měřítek (průměry, sumy) a
* pokročilá vizualizace (Měřidlo / Gauge pro porovnání narozených/zemřelých, Prstencový graf pro podíly rozvodů)
